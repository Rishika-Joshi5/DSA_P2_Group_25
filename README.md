**Algorithms:** Breadth-First Search, Depth First Search

**How to run the project:**
-	Go to main.cpp file, in terminal & run this: 
	o	To build: g++ src/main.cpp src/reader.cpp src/tree.cpp src/food.cpp -o cmake-build-debug/main.exe
	o	To execute: cd cmake-build-debug ./main.exe
	o	(If that doesn’t work, try cd cmake-build-debug; .\main.exe from the cmake-build-debug directory)
-	At the very bottom the time for DFS and BFS will be shown to see which is faster.
-	Go to ui.py file, in terminal run this:
	o	To Build: g++ src/ui.cpp src/reader.cpp src/tree.cpp src/food.cpp -o cmake-build-debug/ui.exe
	o	To execute:  python src/ui.py
-	Pygame.ce 2.5.8 is used, with Python 3.14.2
